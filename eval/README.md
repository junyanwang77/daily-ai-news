# eval — 简报质量评估

`validate_briefing.py` 保证的是**格式合规**：字段填了没有、取值在不在允许集合里。
它保证不了**内容对不对**——一条新闻可以字段齐全、取值合法，同时链接是编的、
「已核实」是瞎标的、和昨天报的是同一条。

这个目录就是补上那一层。它不阻断发布（不进 CI），是离线的分析工具。

## 怎么跑

```bash
python3 eval/extract.py       # 1. 把 archive/ 抽成结构化数据集（秒级，离线）
python3 eval/stats.py         # 2. 离线指标（秒级，不联网）
python3 eval/check_links.py   # 3. 链接可达性（联网，约 3-5 分钟）
```

本机需要代理时，跑第 3 步前先：

```bash
export https_proxy=http://127.0.0.1:7897 http_proxy=http://127.0.0.1:7897
```

`check_links.py` 可选参数：`--limit N` 小规模试跑，`--since YYYY-MM-DD` 只查近期。

产物都在 `eval/data/`（`items.jsonl` / `days.jsonl` / `links.jsonl`），未纳入版本管理。

## 各脚本在测什么

| 脚本 | 测什么 | 能证伪什么 | **测不到什么（天花板）** |
|---|---|---|---|
| `extract.py` | 无判断，只抽取 | — | — |
| `stats.py` | 字段分布、信源集中度、重复报道、链接具体性 | 「自评字段有区分度」<br>「不重复报道」<br>「每条都给了具体文章链接」 | 内容本身是否属实；摘要有没有夸大原文 |
| `check_links.py` | 链接是否真实可达 | 「链接全都有效」 | 链接指向的内容**是不是**那条新闻；被反爬拦截的无法判定 |

### check_links.py 的天花板要特别小心

"链接今天打不开" ≠ "当初是编造的"。页面会被删除、改版、搬迁，这叫链接腐烂。
所以报告按**简报发布距今天数**分组：新简报里就失效的才是编造的强证据；
老简报失效可能只是自然腐烂。**不看这个分组直接读总失效率，会得出错误结论。**

另外约 18% 的链接会返回 401/403/429（反爬），判为 `blocked` 而非死链——
无法判定就不下结论，这是刻意的，不要把它算进失败率。

## 2026-08-09 首次基线（57 篇简报 / 214 条新闻 / 184 个唯一链接）

**通过的检验：**

- **没有证据表明模型编造链接。** 硬失效 7/184。按时长分组：0–14 天 **0%**、
  15–45 天 3.8%、46 天以上 6.2%。这条**单调递增**曲线正是自然腐烂的形状；
  如果是编造，新简报的失效率应该和老简报一样高。这是一个可能被证伪、
  但实际没被证伪的预测。
- **信源不偷懒。** 87 个唯一域名，最集中的只占 8.7%，67% 的域名只出现过一次。
- **上一次质量改进是有效的，而且现在能看见了。** 「核查状态」字段 6 月缺失率 52%，
  7、8 月降到 **0%**——`validate_briefing.py`（2026-07-26 引入）确实锁住了契约。

**发现的问题（按严重度）：**

1. **栏目首页当证据：12/208 = 5.8%，其中 4 条自评「已核实」。**
   如 `anthropic.com/news`、`openai.com/news/` 是新闻列表页，永远 200 OK，
   但内容天天变，读者点进去找不到对应新闻。这是**目前唯一确凿的自评失准**：
   模型在没有可核实证据的情况下标了「已核实」。
2. **跨天重复报道：7 天窗口内至少 8 组标题相似度 > 0.75。**
   OpenAI/Broadcom 芯片（6-27、6-29）、Kimi K3（7-18、7-19）、
   Anthropic 融资（6-10、6-12）等。"今日"的边界没被严格执行。
3. **「核查状态」和「可信度」是同一个信号。** 已核实 → 高：108/108 = **100%**，
   部分核实 → 中：45/46。两个字段完全冗余，实际只有一个维度的信息。
4. **「重要性评分」区间塌缩。** 214 条里 82% 落在 6–8 分，从没出现过 1–3 分，
   均值 7.36。评分没有真正在区分重要性。

**还完全没测的（下一层）：**

- 摘要内容与原文是否相符（有无夸大、编造数字）→ 需要人工标注黄金集或 LLM-as-judge
- 「可信度：高」标得对不对 → 同上
- 时效性：链接页面的发布日期是否真在过去 24 小时内
