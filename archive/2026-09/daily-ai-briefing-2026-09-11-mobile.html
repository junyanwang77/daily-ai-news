先说结论

OpenAI公测Agent API，DeepSeek发新模型，中美同日出手。美国拼AI代理基建，中国拼模型性价比，双向挤压创业公司。开发者可先试用新工具，企业需关注代理支付新规则。

今日最值得关注的 5 件事

1. OpenAI 上线 Agents API 公测版，把 Codex 级 Agent 框架开放给所有开发者

发生了什么：OpenAI 于 9 月 10 日推出 Agents API 公测版，把驱动 Codex 的托管式框架开放给所有开发者，支持长会话管理、自动上下文压缩、工具调用与多代理协作，可在 OpenAI 托管沙箱或自托管环境运行，按 token、工具和容器时长计费，不额外收费。

为什么重要：这是 OpenAI 把内部 Codex 级 Agent 基础设施正式产品化，大幅降低企业和开发者自建复杂 Agent 系统的门槛，是 Agent 基础设施赛道的重要一步。

2. DeepSeek 发布 V4.1 Flash，原生多模态且全面反超此前的 V4 Pro

发生了什么：DeepSeek 于 9 月 10 日正式发布 V4.1 Flash，原生支持多模态视觉理解，API 价格同步下调；官方同时宣布 9 月 14 日中午 12 点起，发往 V4 Pro 的请求将自动转向 V4.1 Flash 并按新价格计费，直至 V4.1 Pro 发布为止。

为什么重要：官方称 V4.1 Flash 在性能、成本、速度上已全面超越此前的 V4 Pro，显示 DeepSeek 持续以高性价比模型对全球 API 市场施压，加剧低成本模型间的竞争。

3. Visa、万事达卡与蚂蚁国际联合发布 AI 代理身份互认框架 KYA

发生了什么：三方于 9 月 10 日联合宣布"Know-Your-Agent（KYA）"互操作框架，尝试打通各自此前独立的 AI 代理身份协议——Visa 的 Trusted Agent Protocol、万事达的 Verifiable Intent、蚂蚁国际的 Agentic Mobile Protocol——用于验证 AI 代理身份并将其行为关联回被授权的个人或企业。

为什么重要：随着 AI Agent 开始代替用户下单、支付，行业需要统一的身份与授权标准；三大支付巨头联手意味着"代理商务（agentic commerce）"的合规基础设施开始成型，将影响未来 AI 购物、自动化支付类产品的落地方式。

4. 月之暗面启动 Kimi 企业合作伙伴计划"登月计划"，首批五家企业签约

发生了什么：月之暗面 9 月 10 日宣布启动 Kimi 企业合作伙伴计划"登月计划"，联合金山云、中软国际、华胜天成、亚信科技、亚康股份等首批伙伴，采用"前线部署工程师（FDE）"共建模式，帮助企业把大模型能力嵌入核心业务流程。

为什么重要：这是国内大模型公司首次采用 FDE 式深度定制交付模式拓展企业市场，且发生在月之暗面此前被曝以保密形式递交港交所 IPO 申请之后，被外界视为其强化 2B 收入故事的关键动作。

5. AI 推理芯片公司 Positron 完成 8.75 亿美元 C 轮融资，估值达 50 亿美元

发生了什么：AI 推理芯片创业公司 Positron 于 9 月 10 日宣布完成 8.75 亿美元 C 轮融资（分两批完成），由 NEA、Atreides Management、Valor Equity Partners 等领投，估值达 50 亿美元，较今年 2 月增长约 5 倍，资金将用于 Asimov 推理芯片流片和 Titan 系统量产。

为什么重要：Positron 主打用成本更低的消费级 LPDDR5X 内存替代供应紧张的 HBM 来做推理加速，反映资本正加速押注"推理算力去 HBM 化"路线，是 AI 芯片供应链多元化的信号之一。

对普通人的影响

今天的消息大多发生在企业和开发者层面，普通用户不会立刻感受到明显变化。简单说：AI 公司之间"打价格战、拼谁的工具更好用"仍在继续，长期看可能让你常用的 AI 产品更便宜或响应更快，但具体哪些 App 会降价、何时降价，目前没有官方消息，不要轻信任何"某产品即将降价/免费"的传言。另外，Visa、万事达卡和蚂蚁国际在推动 AI 代理支付的身份认证标准，这意味着未来可能会出现"AI 帮你自动下单、自动付款"的产品，但这类框架目前还处于行业协议制定阶段，尚未落地到具体消费者产品，暂时无需采取任何行动。

对学习者 / 开发者的影响
  • 可以试用 OpenAI 新开放的 Agents API 公测版，了解托管式 Agent 开发范式（会话管理、上下文压缩、多代理协作），评估是否能替代自建的 Agent 框架。
  • 如果你的应用涉及图像理解或多模态场景，可以关注 DeepSeek V4.1 Flash 的原生多模态能力和更低定价，并注意 9 月 14 日起旧版 V4 Pro 请求会被自动切换至新模型计费，提前检查相关依赖。
  • 如果在做支付、电商类 Agent 应用，建议提前了解 KYA 框架涉及的三种协议（Visa Trusted Agent Protocol、万事达 Verifiable Intent、蚂蚁 Agentic Mobile Protocol），为未来的代理身份认证需求做准备。
对创业者的影响
  • Agent 基础设施正被大厂进一步平台化（OpenAI Agents API 公测），独立 Agent 框架类创业公司的护城河被压缩，差异化更应体现在垂直场景和专有数据，而非底层框架本身。
  • 模型价格持续下探且性能反超上一代（DeepSeek V4.1 Flash 降价并全面超越 V4 Pro），意味着单纯依赖模型 API 转售或简单封装的创业模式，利润空间会进一步被挤压。
  • 中国大模型企业级落地渠道正从"卖模型"转向"卖交付"（月之暗面 FDE 式登月计划），想拿下企业订单的创业者需要考虑是否要配置更重的现场交付能力，这一判断基于单日新闻观察，长期趋势仍需持续验证。
我的判断

我的判断：今天最值得关注的不是单一模型发布，而是 AI 竞争的重心正在从"模型能力"扩散到"基础设施标准"——OpenAI 把 Agent 框架产品化、支付巨头联手定义代理身份标准，说明行业已经默认 AI Agent 会大规模处理真实业务和真实交易，接下来拼的是谁能把这套流程做得更安全、更便宜。同时 DeepSeek 和月之暗面的动作显示，中国厂商仍在用"价格战+重服务交付"两条腿应对竞争。需要提醒的是，月之暗面"登月计划"报道目前只有中文媒体交叉验证、缺乏官方一手公告，其长期效果和 IPO 关联性仍需观察，不宜过度解读为确定性利好。
