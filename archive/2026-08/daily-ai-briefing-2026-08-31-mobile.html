1. 智谱正式纳入MSCI中国指数，8月31日收盘后生效

发生了什么：MSCI于8月12日公布2026年8月指数季度审议结果，将智谱（02513.HK）等33只标的纳入MSCI中国指数，调整已于8月31日收盘后正式生效实施。智谱是本次调入标的中唯一一家港股上市的中国AI大模型企业，也是新增成分股中市值最高的一只。

为什么重要：进入MSCI中国指数意味着同时进入MSCI新兴市场指数乃至全球标准指数体系，将带来跟踪相关指数的被动资金增量配置，是对智谱港股上市后市场认可度的一次重要验证。

2. Kimi K2.5 与 moonshot-v1 系列模型 API 8月31日起全面下线

发生了什么：月之暗面此前于8月4日通知API开发者，kimi-k2.5及moonshot-v1系列模型API将于8月31日正式下线停止服务，建议迁移至kimi-k3、kimi-k2.6等新模型；8月24日 Kimi 官方微博再次确认这一下线时间点，今日为正式执行日。

为什么重要：K2.5是月之暗面首个万亿参数多模态模型，服役仅约7个月即被2.8万亿参数的继任者K3取代，反映出中国大模型厂商当前的产品迭代速度很快，仍在调用旧模型API的开发者需要及时完成迁移，否则服务会中断。

3. 消息称Claude Code每周限额促销将再延长至9月14日，永久涨幅或从50%下调至25%

发生了什么：据日本科技媒体 TechnoEdge 8月30日报道，Anthropic原定8月31日结束的Claude Code周使用限额"+50%"促销将再次延长至9月14日，促销结束后拟推出的永久性提升幅度为25%，低于促销期间的50%。此前 ITmedia、PC Watch、窓の杜 等多家日媒在8月19日前后曾报道该促销"延长至8月31日"。

为什么重要：大量开发者依赖 Claude Code 完成日常编程工作，周使用限额规则直接影响其能否稳定使用该工具；若永久涨幅最终确定为25%而非50%，意味着9月中旬后可用配额会明显回落。
